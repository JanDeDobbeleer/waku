Welcome to the waku wiki!

Start with the [installation guide](Installation),
then use these references:

- [Getting started](Getting-started): try the built-in bar or a ready-made port.
- [Customization](Customization): arrange widgets, change a theme and add keys.
- [waku startup reference](waku): config homes and startup options.
- [wakuc command reference](wakuc): control the bar, windows, desktops and startup.
- [wakukeys hotkey guide](wakukeys): configure key bindings and control the daemon.
- [QML reference](QML-reference): modules, common types and property metadata.
- [Shell author notes](https://github.com/JanDeDobbeleer/waku/blob/main/docs/shells.md): write or
  port a QML shell.
- [Troubleshooting](Troubleshooting)
  and [diagnostic logging](https://github.com/JanDeDobbeleer/waku/blob/main/docs/logging.md).

The wiki describes the development version. Installed releases may differ. Its
[source](https://github.com/JanDeDobbeleer/waku/tree/main/docs/wiki) lives with the code. See
[Maintaining the wiki](Maintaining-the-wiki) for publishing and release checks.
