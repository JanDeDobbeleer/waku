# Archive

These documents describe the retired Qt Widgets build (yasb-native), the C++ port of YASB that
wabar replaced. The code they refer to is gone from the working tree; it is at the git tag
`widgets-main-final` (`e2b602f`, the last Widgets `main` and the second parent of the merge
`ba442f5`; `git log ba442f5^2` walks its history). Paths, targets and commands in these files are
those of that tag and no longer exist on the main line. The tag `yasb-native-final` (`58fd9ac`) is
an earlier point on the Qt Quick line that still held the Widgets sources next to the `spike/`
prototype; it is not the last Widgets build.
